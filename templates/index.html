📋 iPhoneの設定方法

このサーバーをDNSとして使用するようiPhoneを設定してください。


このサーバーのIPアドレス：{{ local_ip }}

  1. iPhoneの 設定 → Wi-Fi を開く
  2. 接続中のWi-Fiの ⓘ をタップ
  3. DNSを設定 → 手動 を選択
  4. 既存のサーバーを削除し、{{ local_ip }} を追加
  5. 保存 をタップ

⚠️ DNSブロックには上の「DNSブロック開始」ボタンが必要です（要 sudo でport 53）。
